# Deep Research Companion — Gemini CLI extension

This extension bundles the `deep-research-companion` skill in `skills/deep-research-companion/`. When the user requests Kanıt Hattı, Deep Research Companion, research prompt writing, or source checking, activate that skill and follow its selected reference. Reply in the user's language.

Use available web tools to open cited sources. Never report a source as read when it was not retrieved. Numerical matches alone are not semantic verification. Do not run clipboard monitoring or install document dependencies without a task that requires them. Respect the user's workspace and permission rules.

The Gemini app Gem is a separate chat setup; installing this extension does not create a Gem.
